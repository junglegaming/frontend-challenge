# Página `design-system` — Catálogo visual

**Rota:** `/design-system` (apenas em desenvolvimento ou no build de demonstração com mocks ativos; fora da navegação)

Mostra os tokens (cores com contraste, tipografia, espaçamento, raios), os ícones oficiais e os componentes de
`src/shared/ui` com seus estados. Serve de alvo para os snapshots Playwright (`e2e/design-system`) e de referência para
revisar qualquer desvio do padrão (`specs/001-design-system-standards/contracts`).

**Usa os domínios:** nenhum.
